# ArchCatalog
ArchCatalog — self-contained architecture knowledge catalog in a single HTML file with LLM-powered analysis (external or local via Ollama). Design patterns &amp; anti-patterns, wiki, diagram editor (C4, UML, ArchiMate, BPMN 2.0), Mermaid, interactive relationship graph, export to MD/JSON/PDF/DrawIO. JSON-configurable. No server, no build.
